## 🎯 عن المشروع

**صمام الأمان** هي منصة ويب عربية مجانية تساعد الآباء والأمهات على فهم مخاطر الألعاب الإلكترونية التي يستخدمها أطفالهم. نُحلّل كل لعبة من **4 محاور أساسية**:

| المحور | الوصف |
|--------|-------|
| 🛡️ الخصوصية | تسريب البيانات والمعلومات الشخصية |
| 👥 الغرباء | مخاطر التواصل والاستدراج |
| 💳 الأموال | المشتريات العدوانية والصناديق العشوائية |
| ⏰ الإدمان | التصميم الإدماني والمحتوى غير الملائم |

## 🎮 الألعاب المُحلّلة

يتضمن المشروع تحليل **26 لعبة وتطبيق** من أشهر الألعاب في العالم العربي، منها: Roblox, PUBG, Minecraft, Fortnite, TikTok, Brawl Stars, Free Fire, والمزيد.

## ⚙️ التقنيات

- **React 19** — واجهة المستخدم
- **Vite 8** — أداة البناء
- **TailwindCSS 4** — التنسيق
- **Framer Motion** — الرسوم المتحركة
- **Lucide React** — الأيقونات

## 🚀 التشغيل

```bash
# تثبيت التبعيات
npm install

# تشغيل خادم التطوير
npm run dev

# بناء نسخة الإنتاج
npm run build
```
